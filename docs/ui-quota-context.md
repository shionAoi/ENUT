# Quota, Usage and Context views

All tools shows installed tools and their reported quotas. The **?** button reveals details including reset information.
Unsupported allowances remain unavailable; local runtimes have no subscription quota.
Connect and Revoke manage the same per-tool remembered permission in All tools and Context. Gemini Connect explicitly opens native login and code entry; app startup reuses remembered permission and CLI credentials without opening a browser. Revoke deletes monitor-owned history and approval, not CLI credentials or source transcripts.

Usage selects one installed tool independently of the All tools filter. Each bar shows one
model's token count for the displayed UTC period. Only complete dated local model records
qualify; API totals, partial counters and quota balances are not substitutions.
Approved local history can be displayed offline. Missing records do not mean zero usage.

Context follows Usage in navigation. Select a tool to see reported MCP names/status and
installed skill names. Configured is not connected. A received empty list differs from
unavailable discovery; the source note explains partial failures. Skill names are not
actions. The monitor publishes no MCP commands, URLs, environment values, private paths,
credential material or skill bodies. Permission is required for local metadata discovery
as well as supported native status requests. Native CLIs may manage their own saved
authentication, as disclosed per tool.

Neither view shows cached metadata without permission. Context also requires a connection. EZ Control renders live RAM and CPU gauges plus an expandable per-agent subprocess/command tree (`TASK`, `Memory`, `% CPU`, `ID`) strictly for approved connected integrations without process termination controls. Browser
preview remains empty and cannot connect tools. The existing light/dark themes, compact
480×720 desktop window, tray controls and Settings/reporting flows are preserved.
Active integrations use Antigravity instead of Gemini and include OpenCode and Hermes;
legacy Gemini rendering remains compatible with existing parser fixtures only.
